# 🇬🇧 Неправильные глаголы английского языка — справочник и тренажёр

Интерактивный тренажёр по **152 неправильным глаголам английского языка** (британское произношение). Всё приложение — **один HTML-файл** (`index.html`), работает офлайн в любом браузере.

Материалы подготовил: **Бабков Иван Леонидович** · ✉ [i@ibabkow.ru](mailto:i@ibabkow.ru)

## ✨ Возможности

- 📋 **Все глаголы** — таблица 152 глаголов: V1 · V2 · V3, транскрипция IPA (UK), перевод, озвучка каждой формы и всех трёх сразу
- 📘 **Справочник** — 90+ основных глаголов
- 💡 **По группам** — глаголы, объединённые по типу образования форм (мнемоника вместо зубрёжки)
- 🃏 **Карточки** — флеш-карточки с переворотом и перемешиванием
- 📝 **Тренажёр** — три режима:
  - **Выбор из 4 вариантов** — неверные варианты генерируются как *правдоподобные ошибочные формы* (`goed`, `gone • went`, `cut • cutted`); при верном ответе автоматически озвучиваются все 3 формы глагола, нажатие на зелёный вариант повторяет прослушивание; клавиши `1–4`
  - **Ввод V2 и V3** — печать форм с клавиатуры (принимаются варианты `burnt/burned`, `was/were`)
  - **Ввод перевода** — печать русского перевода
- 📊 Прогресс-бар, серия ответов 🔥, разбор ошибок, отметки «выучено», статистика

## 🚀 Запуск

**Просто откройте `index.html` в браузере** — установка не требуется, интернет не нужен.

Озвучка выполняется встроенным синтезатором речи браузера (`speechSynthesis`, `en-GB`). Весь прогресс хранится локально в `localStorage` — никакие данные не уходят на серверы.

> 💡 Есть и веб-версия с качественным серверным озвучиванием (Next.js + TTS API) — репозиторий проекта.
