# The Oxford 3000™ — Мой словарь английского

Интерактивный статический сайт для изучения базового словаря английского языка (The Oxford 3000™). Проект содержит набор страниц с уровнями владения (A1, A2, B1, B2), интерактивные карточки, тесты и простую систему отслеживания прогресса в браузере.

## Особенности
- Уровни: A1 / Starter, A2 / Elementary, B1 / Pre-Intermediate, B2 / Intermediate
- Интерфейс на русском языке
- Карточки (flashcards) для запоминания слов
- Тесты (открытые/закрытые)
- Озвучивание слов (произношение)
- Отслеживание прогресса (данные хранятся локально в браузере — localStorage)
- Режимы обучения: список, карточки, тесты
- Разделы с информацией об авторе и описанием методики

## Структура репозитория
- `index.html` — главная страница с обзором уровней и ссылками на страницы уровней
- Страницы уровней (ссылки на них есть в `index.html`):
  - `my_english_words_3000_А1.html` (A1)
  - `my_english_words_3000_A2.html` (A2)
  - `my_english_words_3000_B1.html` (B1)
  - `my_english_words_3000_B2.html` (B2)
  (Файлы уровней предполагаются в репозитории и доступны через ссылки с главной страницы.)

## Как использовать локально
1. Склонируйте репозиторий:
   git clone https://github.com/ICU88ivan/english.git
2. Откройте `index.html` в браузере — либо двойным кликом, либо запустив локальный сервер, например:
   python -m http.server 8000
   затем откройте http://localhost:8000

## Развертывание
- Это статический сайт — удобно развернуть на GitHub Pages:
  - В настройках репозитория (Settings → Pages) выбрать ветку и папку (обычно `main` и `/root`).
  - После активации сайт будет доступен по адресу `https://ICU88ivan.github.io/english/`.

## Данные и приватность
- Прогресс и личные настройки хранятся локально в браузере (localStorage). Никакие данные не передаются на серверы по умолчанию.
